CIP Plant

Daily plant sheet app for shift foremen (Android).

Opened this from WhatsApp?

Tap ⋮ (top right) → Open in Chrome first. Downloads often don't work inside WhatsApp.

Download the app

Latest version: 1.0.18
About 37 MB. Works on Android 7 and newer.

Install

  1. Tap Download the app. If Chrome says "File might be harmful", tap Download anyway.
  2. When it finishes, tap Open (or find it in Files → Downloads).
  3. If asked, allow Install unknown apps for Chrome, then go back.
  4. Tap Install. If Play Protect says the app is unsafe or blocked, tap More details → Install anyway. This shows for any app that isn't from the Play Store.
  5. Open CIP Plant and sign in with the username and password your manager gave you. The first sign-in needs signal; after that it works offline.

Says "invalid" or "App not installed"?

  • Check the phone is Android 7 or newer: Settings → About phone → Android version.
  • Download again in Chrome (not inside WhatsApp) and make sure it finishes completely.
  • Still failing? Send your manager a screenshot of the message and the phone model.

Updating

When there's a new version, download and install it the same way. It installs over the old one and keeps your data. To check you're up to date, the version is shown at the top of the app under your name (e.g. "v1.0.18") and should match the latest version above. Don't uninstall first, or any readings that haven't been sent yet will be lost.
